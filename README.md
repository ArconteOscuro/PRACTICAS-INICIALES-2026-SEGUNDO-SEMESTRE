\## 🛠️ Bitácora de Fallas y Soporte (Helpdesk)



\### Casos Reportados durante el Mantenimiento:

\* \*\*Falla / Issue  (Conector de Ventilador Sensible):\*\* Durante el desensamblaje, se identificó que el conector del ventilador de la GPU a la placa madre contaba con una reparación previa muy delicada (cinta amarilla). 

&#x20; \* \*\*Solución Aplicada:\*\* Para evitar daños irreversibles en los pines de la placa, se tomó la decisión técnica de NO desconectar el ventilador, procediendo únicamente a apartarlo con cuidado para liberar el espacio necesario y extraer el disipador principal sin comprometer la integridad del hardware.
